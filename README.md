# next5

next5 is a lightweight, non‑Copy‑on‑Write filesystem for Linux.  
It is built for those who prefer **simplicity, transparency,  
and explicit control** over implicit safety nets.

next5 does not try to replace existing filesystems.  
It offers an alternative path — one that respects the user's  
right to decide how storage behaves.
